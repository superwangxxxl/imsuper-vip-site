常见问题 ​

安装与设置 ​

Q：在哪些设备上能用？ 官方文档列出的平台：

  • macOS（Apple 芯片和 Intel 都行）
  • Windows（x64 和 Arm64）
  • Linux（x64 和 Arm64，有 .deb、.rpm 和 AppImage 三种安装包）
  • iPhone（iOS 18 及以上），iPad（iPadOS 18 及以上）
  • Android 9 及以上

同一个账号登录后，Bot 和对话在各设备之间同步。手机上用同一个账号登录即可，不需要重新订阅。

Q：Grok Bot 和 Grok 聊天 App 是一回事吗？ 不是，是两个不同的应用。Grok App 里的额度提示、付款墙和 Grok Bot 无关；Grok Bot 的用量在 Grok Bot 应用的 设置 → Usage & Billing 里看。

Q：能自己选模型吗？ 不能。Grok Bot 会为每个任务自动选择模型，没有模型选择器。

Q：界面能改成中文吗？ 能。在设置里选 Language。桌面端可以选「跟随系统」，有 20 多种语言，包括简体和繁体中文。

Q：需要什么订阅？ Grok Bot 需要符合条件的订阅方案才能使用，相关方案和价格仍在调整中。本站不列具体价格和套餐名称，请以官方最新说明为准。

Q：能用语音吗？ 能。桌面端按 Cmd/Ctrl + D 语音输入；手机上点听写按钮。也可以发起语音聊天，Bot 还能回你语音消息。

带操作按钮的 iPhone 还可以一按就开始语音聊天：把 Grok Bot App 更新到 1.16 并打开一次，再到 设置 → 操作按钮 → 快捷指令，搜 "Grok Bot"，选 Start Voice Chat。没有操作按钮的机型，可以用"轻点背面"或 Siri 运行同一个快捷指令，见日更：iPhone 操作按钮一按就和 Bot 对话。

Q：能在 X 上直接把帖子交给 Bot 吗？ 能。回复那条帖子时写 @bot 加上你的要求，比如"@bot 把这条里提到的工具整理成表格"，你的主 Bot 就会收到帖子和要求并开工，结果留在 Grok Bot App 里，X 上只有一句确认。前提是在 grok.com 把 X 账号连到 Grok 账号，并且至少有一个自己的 Bot。@bot 没回复就说明没转过去，常见原因（地区未开放、同时 @ 了 @grok、帖子带视频等）见日更：回复一句 @bot 就交给你的 Bot。

Q：我该先建几个 Bot？ 一个就够。先让它把一件具体的事做好，等工作明显分成几块时再拆，见多 Bot 分工协作。

Q：关掉电脑，Bot 还会干活吗？ 会。任务在云电脑上运行，关掉应用、合上电脑或锁屏手机都不影响正在进行的工作和例程。

例外是要在你自己电脑上做的事：电脑睡着了，Bot 就连不上它。Mac 上光设置"息屏不睡眠"还不够，macOS 的 App Nap 也会让 Grok Bot App 暂停，要一起关掉，做法见在自己电脑上干活。

用量与额度 ​

Q：Bot 突然不回复，提示用量用完了，是坏了吗？ 不是。Grok Bot 的用量按周期发放（官方说明为每周重置）。用完后可以等待重置，或按官方渠道增加额度。具体规则以官方最新说明为准。

Q：怎么省用量？

  • 例程频率够用就好，简报一天一次通常足够。
  • 事件触发写得窄一些，不要"每条消息都处理"。
  • 调研任务说明"快速版"还是"深度版"。
  • 有连接器就用连接器，比反复操作网页更省。
  • 例程第一步先查"有没有新内容"，没有就直接结束。
  • 规则固定的抓数、比对写成脚本定时跑，只把变化交给 Bot；定型的重活交给 Codex CLI、Claude Code 这类命令行工具，Bot 只派活和验收。详见让 Bot 当工头：三层分工法。

Q：设了花费上限，任务会被立刻中断吗？ 不一定。官方说明上限不会中断正在运行的任务，因此可能略微超出。

服务故障与排查 ​

Q：怎么判断是不是 Grok Bot 挂了？ 打开 status.cursor.com 看 Grok Bot 那一行，应用里不显示服务状态。有故障时不要重置云电脑、不要重装应用，两者都修不好服务端问题，重置还可能丢掉最近的改动。等恢复后重发消息即可。完整排查顺序见日更：Bot 不回复了？按这个顺序排查。

Q：我的聊天或 Bot 不见了？ 通常没有被删。依次：完全退出再打开 → 在另一台设备上看 → 侧边栏底部的 Hidden Bots → 确认登录的是同一个账号。不要用恢复或重置去找。

Q：提示云电脑磁盘空间不足？ 说的是 Bot 的云电脑，不是你的笔记本。新版本里 Bot 会提醒一次、列出最大的文件，你同意后才删，聊天记录不受影响。

Q：要联系官方支持，准备什么？ 账号邮箱、版本信息（账户菜单 → Support → About → Copy version info）、截图、请求 ID（右键那条消息 → Copy request ID）。

云电脑卡住了 ​

Q：Bot 一直显示在工作，但没有进展？ 先打开电脑预览看看它停在哪一步，常见原因是遇到登录页、验证码或弹窗。可以直接问：

text
你现在卡在哪一步？截图给我看，并说明需要我做什么。

Q：云电脑连不上怎么办？ 从轻到重：重试或重新打开对话 → 重启应用并检查更新 → 使用界面提供的恢复选项 → 在设置中更新云电脑 → 最后才考虑重置。对话记录不受影响，但重置前未保存的最新改动可能丢失。详见云电脑怎么用。

Q：某个网站总是登录失效？ 有些网站会定期要求重新验证。让 Bot 遇到时暂停并通知你，由你接管完成登录，不要让它想办法绕过。

Q：网站拦截 Bot、一直超时或连接出错？ 有些网站会拒绝来自云电脑共享网络的连接，这时更新、恢复、重置都没用。到 设置 → Computer → Your computer 打开 Route traffic through this computer，让 Bot 的浏览器走你自己电脑的网络（需要桌面端开着）；或者用 Execution on this computer 让命令在你的电脑上执行。详见日更：网站总拦 Bot、一直超时？

Q：审批卡片过期了，动作没执行？ 例程或其他 Bot 发起的工作中的审批，大约 10 分钟无人处理就会过期。让 Bot 重试即可；常用且可信的动作可以考虑"始终允许"，或打开通知避免错过。

多 Bot 与分享 ​

Q：几个 Bot 能同时干活吗？ 能。它们可以并行思考、调用连接器、处理文件。每个 Bot 在共享的云电脑上有自己的屏幕，但一个 Bot 同一时间只能在自己屏幕上做一件操作电脑的任务。

Q：能把我调教好的 Bot 分享给别人吗？ 能。在分享菜单里选 Create template，再 Copy link，可以选公开链接或仅团队可见。对方拿到的是一份副本：拿不到你的电脑、登录状态和聊天记录，但能看到 Bot 的配置。所以分享前把描述里的密钥、内部信息删干净。

Q：能演示给 Bot 看，让它学会吗？ 在提供「Teach a task」的版本里可以：在电脑视图里录一段浏览器操作（最长 10 分钟），Bot 会把它整理成一份技能草稿，你审一遍、测一次再用。这个功能是逐步开放的，你那里没有也正常。

隐私与安全 ​

Q：我的密码会被 Bot 看到吗？ 按照设计，密码、验证码通过接管电脑或安全表单输入，不进入聊天记录。请不要在对话里直接发送密码。

Q：不同 Bot 之间的数据是隔离的吗？ 对话和记忆按 Bot 区分，但云电脑上的文件、浏览器登录和命令行凭证是你所有 Bot 共享的。不同用户之间则是严格隔离的。

Q：数据会被用于训练吗？ 遵循你账号的隐私设置和官方隐私政策，以官方最新说明为准。

Q：不再使用某个项目时要做什么？ 暂停或删除相关例程 → 退出网站登录 → 移除连接器并撤销授权 → 删除云电脑上的敏感文件 → 隐藏或删除 Bot。注意：删除 Bot 不会自动清除共享电脑上的文件。

找不到答案？

直接问你的 Bot："这个功能在哪里设置？"它可以帮你查官方文档。涉及账号和订阅计费的问题，以官方帮助中心为准。
