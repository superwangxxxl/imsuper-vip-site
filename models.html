怎么选 ​

排行是公开评测的平均水平，不能代替你的业务。下面的「依据」直接取自本页三张表的当前数据，每天随数据一起更新；除最后一行外，都不是我们亲手跑出来的结论。

用途怎么挑依据（本页当前数据）
写代码从「综合智力」前几名里挑你能开通 API 的型号；代码一次写对，比单价便宜更省事 智力榜第 1：Claude Opus 5.5 · Max，57.6 分；前 3 名都出自 Anthropic
日常对话、写作智力中上、回得快就够用：在「速度」表里挑智力分不掉队的Claude Opus 5.5 · Max 同时在智力榜第 1、速度榜第 3：57.6 分，96 tok/s
便宜跑量（批量翻译、分类、摘要）先看「价格」表，拿几十条真实样本比质量，再决定放量 价格榜第 1：Muse Spark 1.3 · Max，混合价 $2.00/1M，智力 48.1 分
本地免费跑、数据不出电脑用 Ollama 在自己电脑上跑开源模型，不按 token 计费；小模型会出错，结果要自己核对✅ 已实测，看教程

看表前要知道的 ​

  • 散点用本页三张表里同时有该项分数和混合价的型号当场画；只有这样的维度才出页签，切换后重算点和斩杀线，不另打分。
  • 「速度」「价格」两张表只在综合智力前 30 名里排，免得被很弱的小模型占满。
  • 价格是输入和输出按 3:1 混合后的单价，单位是美元 / 每百万 token。真实花费取决于你输入多、还是输出多。
  • 速度是各家 API 的中位数，高峰期会慢一些；同一个模型换个服务商，速度和价格都可能不同。
  • 表里的「—」表示 Artificial Analysis 暂时没有这项数据，比如没有公开 API 的模型测不了速度和价格；这类模型也不会出现在对应的柱状图和散点里。
  • 「数据更新于」写的是 Artificial Analysis 的数字最近一次变化的日期，不是我们检查的日期。

觉得有用就先收藏 🔖，下次选模型前打开看一眼。
