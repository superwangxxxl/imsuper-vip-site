刷 X 看到好帖，回复一句「@bot」就把它交给你的 Bot ​

刷到一条值得研究的帖子：一份工具清单、一篇长教程、一个新发布的项目。以前要复制链接、打开 Grok Bot、粘贴、再交代要做什么。现在直接在那条帖子下面回复 @bot 加一句要求就行。

按官方文档：@bot 会在 X 上回一句短话，确认已经交给你的 Grok Bot；你的主 Bot 随即在云电脑上开工，过程和结果都留在 Grok Bot App 的对话里，不会公开发在 X 上。

Bot 能拿到什么 ​

你的这条回复、你回复的那条帖子，以及两者引用的帖子（包括里面的图片）。所以直接回复在原帖下面效果最好，不用另外贴链接。

开通前要满足的条件 ​

  • 在 grok.com 的 设置 → Account 里，把你的 X 账号连到 Grok 账号（点 𝕏 Account 旁边的 Connect）。
  • 同一个 Grok 账号开通了 Grok Bot，并且至少有一个你自己的 Bot。别人分享给你的 Bot 接不了这类任务。
  • 第一次成功时，X 会提醒你：这类请求会自动开工，用的是你的 Grok Bot 用量。
  • X 插件（搜帖子、读时间线）不是必需的，没装也能转交。

5 句好用的写法 ​

回复时 @bot 后面直接写要求，越具体越好：

text
@bot 把这条帖子里提到的工具逐个查一下：官网、开源许可证、最近一次更新时间，做成表格放到我的资料库，别关注任何人
text
@bot 这个串讲的方法帮我用到我的周报例程上，先给我改动方案，别直接改
text
@bot 读完这篇长文，提炼 5 条我能照着做的步骤，每条附原文对应段落
text
@bot 这个 GitHub 项目帮我评估一下：能不能装在你的电脑上用、要哪些权限、有没有风险。先别安装
text
@bot 这条帖子说的省用量的办法，对照检查我现在的例程，列出可以合并或降低频率的，等我确认再改

最后一句有真实用例：@AiBraders 在一条讲省用量的帖子下 @bot，Bot 读完后检查了他所有的 Bot，删减了 4 个例程。我们建议加上"等我确认再改"，改例程这种事先看方案更稳。

@bot 不回你？逐条查 ​

官方说明：@bot 没回复，就说明你的 Bot 没收到。常见原因：

情况怎么办
你的 X 账号登记的国家或地区暂不支持（目前不支持澳大利亚、英国、欧盟、冰岛、列支敦士登、挪威；X 只登记了大区或没有登记国家的也不行）只看 X 记录的账号所在地，换 VPN、换位置都没用
你回复的串里已经有人 @bot，但你自己没写 @bot自己再写一次 @bot
同一条里还 @ 了 @grok去掉 @grok 再发
你的帖子、被回复的帖子或被引用的帖子里有视频或 GIF换一条不带视频的帖子，或把链接发到 App 里
内容没通过平台审核换个说法
Grok Bot 没连到 Grok 账号，或本周用量用完去 App 里确认

@bot 回的是 "Sign up for Grok Bot" 说明 X 账号没连 Grok 账号；回 "Grok Bot isn't set up yet" 说明连上了，但你还没有自己的 Bot，先去 App 里建一个。

注意 ​

  • @bot 的回复是公开的，但只有一句确认，你的要求本身也是公开回复。别在回复里写私人信息，具体要求可以简短写，细节到 App 里补。
  • 转交的任务和你在 App 里交代的一样，发消息、下单、删除之类照样先出审批卡片。
