Anthropic 于 2026-11-09 发布 Claude Fable 5.2（claude-fable-5-2）。默认 1M 上下文、12.8 万输出上限，输入/输出单价降到 $8 / $40（每百万 token），可选 fast mode。多数日常任务官方仍建议先用 Opus 5.5；从 5.1 切过来有 4 处改动要先看，其中 3 处会直接 400。

Claude Fable 5.2 上线：输入 $8 / 输出 $40，长程 Agent 用；从 5.1 切过去前先看 4 处改动（3 处会直接 400） ​

发生了什么 ​

Anthropic 在 2026-11-09 发布 Claude Fable 5.2（API 模型 ID：claude-fable-5-2），面向要求高的推理和长时间 Agent 任务。同日还有 Claude Mythos 5.2（claude-mythos-5-2），能力相同，但只开放给通过 Anthropic 核验项目（如 Cyber Verification Program）的组织。

以上日期与规格来自官方公告和 Claude Platform 文档，不是我们实测。本站上线日为 2026-11-10。

官方原文：

Developers can get started with claude-fable-5-2 on the Claude Platform.

新变化 / 能干什么 ​

  • 默认 100 万 token 上下文（也是上限），单次最多 12.8 万 输出 token；自适应思考一直开着，用 effort 控制深度，API 默认 high
  • 单价低于 5.1：输入 $8 / 输出 $40（每百万 token）。5.1 是 $10 / $50。缓存读取 $0.20；5 分钟缓存写入 $10，1 小时缓存写入 $16；Batch 为 $4 / $20（官方便宜一半）
  • 可选 fast mode：官方写输出速度最高约 2.5 倍，价格是 $16 / $80。在 Claude API 的 Messages 请求里设 speed: "fast"，不必加 beta 头；Microsoft Foundry（Anthropic 托管）上是单独模型 ID claude-fable-5-2-fast
  • 可用平台包括：Claude API、Amazon Bedrock（global.anthropic.claude-fable-5-2 或 us.anthropic.claude-fable-5-2，只在 bedrock-runtime 端点）、AWS 上的 Claude Platform、Google Cloud（Anthropic 托管 / Google 托管）、Microsoft Foundry
  • 官方建议：多数写代码和知识工作先用 Claude Opus 5.5；评测仍不够再用 Fable 5.2

适用条件 ​

  • Fable 5.2：Claude API 上对客户开放（合作云见各平台文档）
  • Mythos 5.2：须通过核验项目，或联系客户团队
  • 消费端：公告只写「符合条件的订阅套餐」。Claude 定价页（2026-11-12 核对）写的是 Max、Ultra 含 Fable，最高占每周额度的一半；Pro 写的是 Fable 用 usage credits 结算。各套餐能不能用、怎么算，以定价页当天为准
  • 公告还写：上线当周（限时活动），符合条件的订阅套餐会有额外 Fable 用量（含 Fable 的套餐/席位按订阅时长给 1–3 次 Fable 重置；Pro 与 Team 标准席位的周限额里，Fable 最高可占到 50%）。以公告原文为准，活动是否仍有效请打开公告页核对

限制 / 坑（从 5.1 切过来尤其要看） ​

官方列出 4 处可能让旧代码出问题的改动，其中 1、3、4 会直接返回 400，第 2 条只是悄悄丢掉推理、请求仍然成功：

  1. 前缀检查对所有账号生效：如果你改了 system、tools 或更早的消息，又把 5.2 的 thinking 块送回去，会 400。5.1 默认只对 2026-08-31 及之后新建的账号这样报错
  2. 5.2 的 thinking 块只有 Fable 5.2 / Mythos 5.2 能读；切回 Opus 5.5 或 Fable 5.1 时，这些推理会被丢掉（请求仍会成功）
  3. 计算机操作须用 computer_toolset_20260801；继续声明旧的 computer_20251124 会 400（Amazon Bedrock 除外）
  4. advisor 工具（beta）：执行模型如果是 Fable 5.2 / Mythos 5.2，顾问也只能是这两个之一

另外（官方，不是实测）：

  • 不能关思考；thinking 设成 disabled 或带 budget_tokens 的手动延长思考会 400
  • 强制调用工具（tool_choice 为 any 或指定某个 tool）会 400
  • 官方写明省略 temperature、top_p、top_k（具体哪些取值会 400，见官方文档的 Sampling parameters 一节）
  • 须保留 30 天数据；除非 Anthropic 另行授权，否则不能走零保留（ZDR）。不满足会 400
  • 不支持 Priority Tier
  • 可靠知识截止日期为 2026-06
  • 文档写承诺下线不早于 2027-11-09
  • Fable 对高风险网络安全和多数生物学研究任务有安全分类器拦截；这类任务官方导向 Mythos 核验通道
